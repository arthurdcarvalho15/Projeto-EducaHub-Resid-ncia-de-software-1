# EducaHub

- Projeto local em HTML, CSS e JavaScript puro, sem framework ou compilador.
- Páginas: index.html e pastas por rota, cada uma com index.html.
- Estilos em assets/css/, imagens em assets/images/ e fontes em assets/fonts/.
- Módulos JavaScript em assets/js/: components/, pages/, scripts/, utils/ e services/.
- Preserve as 44 rotas, a identidade visual, os cinco perfis e as práticas de docs/acessibilidade.md.
- O login e a matrícula são simulações; não apresentar a simulação como envio real.
- Use node tools/server.mjs para servir localmente na porta 4321.
- Antes de concluir: npm run format, npm run lint, npm test e npm run build.
- Não mantenha dependências instaladas, backups da migração ou cópias de dist/ no código-fonte. A pasta dist/ é gerada por npm run build.
